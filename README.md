# SERENIA

## Sistema de Administración de Alojamientos

Estado del proyecto:
🟢 En desarrollo

Objetivo:

Construir un sistema simple, rápido y modular para la administración de alojamientos temporarios.

Primer implementación:
La Rústica

Principios del proyecto:

- El calendario es el centro del sistema.
- Una reserva debe poder cargarse en menos de un minuto.
- La configuración nunca debe impedir trabajar.
- Todo módulo debe ser reutilizable.
- Ningún cambio debe romper lo que ya funciona.

Versión actual:

v1.0 - Migración del monolito.
